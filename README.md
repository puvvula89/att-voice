# att-voice

Voice-agent reference project on Google ADK + the Gemini Live API. One numbered folder
per use case, each independently runnable.

- **[`01-phone-upgrade`](01-phone-upgrade/README.md)** — voice phone-upgrade agent (line picker →
  phone options → confirmation → receipt), driven by voice or by clicking. Run locally or deploy
  the whole stack to Google Cloud with one command — see its
  [README](01-phone-upgrade/README.md) and [DEPLOY.md](01-phone-upgrade/DEPLOY.md).
